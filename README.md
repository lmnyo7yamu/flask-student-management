# Flask Student Management System

This is a simple web-based Student Management System built with Python, Flask, and SQLite. It allows users to add new student records, view the list of registered students, and export the data.

## Features
* **Add Students:** A form to input student details (Name, Age, Address, City, PIN) with full validation.
* **View Records:** A styled table displaying all students currently stored in the database.
* **Export to CSV:** A one-click button to download the student list as a `.csv` file.
* **Dark Mode:** A toggle button to switch between light and dark themes seamlessly.
* **Responsive UI:** Clean and centered layout with hover effects, rounded corners, and proper spacing using custom CSS.

## Technologies Used
* **Backend:** Python, Flask
* **Database:** SQLite
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (for Dark Mode)
